## 🥀 The Dilemma: Why do 90% of brilliant prototypes die?

Every software engineer, student, and hackathon builder has a folder of abandoned side projects. When time runs out, exams arrive, or priorities shift, valuable code sits rotted in forgotten private repositories.

* **Lost Context:** Users forget what was completed, what was remaining, and why progress stopped.
* **Unclear Direction:** Builders cannot confidently decide whether to continue, pivot, or archive.
* **Restart Friction:** Returning to an old project months later feels like starting from zero.
* **The Decision Vacuum:** GitHub stores code, Notes hold ideas, and Task apps track to-dos — but none tell you **“What now?”**.

---

## 🌿 The Solution: The Project Graveyard Conservatory

**Project Graveyard** preserves context, evaluates possible revival paths, and turns a stalled repository into practical next actions through a dignified **Capture ➔ Evaluate ➔ Act** methodology.

```
       [ Abandoned GitHub Repo ]
                  │
                  ▼
         1. CAPTURE & AUTOPSY
       (Context, Debt, Epitaph)
                  │
                  ▼
         2. EVALUATE & SCORE
    (Revival Compass Viability 0-100)
                  │
                  ▼
         3. ACT & REGENERATE
  (2-Hour Sprint Roadmap | Code Salvage)
```

---

## 🏛️ Four Tools. One Clear Purpose.

### 1. 🪦 The Crypt & Preserved Specimens Catalog
* Vaulted project specimens with forensic failure classifications (Time Shortage, Scope Creep, Technical Blocker, Hackathon Ended).
* Interactive **Memorial Autopsy Vitrine** displaying git history, completion velocity (%), and technical debts.

### 2. 🧭 The Revival Compass
* Multi-vector AI viability engine analyzing technical freshness, architecture intactness, and market timing.
* Recommends concrete paths: **Continue**, **Repurpose**, or **Archive**.
* Generates a timeboxed **120-Minute Revival Sprint Roadmap** with actionable checklists.

### 3. 📦 The Salvage Yard
* Extract clean, zero-dependency code modules (Auth JWT engines, LDAP directory scrapers, Canvas vector loops).
* **1-Click JSZip Export:** Downloads sanitized production-ready packages directly in the browser.

### 4. 🧬 Graft Studio & 3D AI Forensic Copilot
* **Graft Studio:** Cross-pollinate reusable components from multiple dead repositories to assemble a brand-new MVP.
* **3D Motion AI Copilot (`Ask AI Chat`):** Floating ceramic interactive assistant in live floating motion to answer forensic queries about buried projects.

## 🎨 Design Philosophy: Warm Sandstone Claymorphism

Designed specifically to avoid cold corporate SaaS dashboards:
* **Tactile Soft UI:** 3D claymorphic bevels, soft ambient drop shadows, and warm sandstone tones (`#FAF6F0`, `#DE8553`).
* **Calming Ambience:** Built-in 432Hz botanical harmonic sound synthesizer powered by the Web Audio API.
* **Universal Responsiveness:** Flawless layout scaling across desktop workstations, tablets, and mobile displays.

---

## 🛠️ Technical Architecture

* **Frontend Framework:** React 19 + TypeScript (Strict Mode)
* **Build Tool:** Vite 8 (Sub-second HMR & optimized production bundling)
* **Styling Engine:** Tailwind CSS v4 + Custom Claymorphic Theme Variables
* **Audio Synthesizer:** Web Audio API (Native 432Hz dual-oscillator harmonic chime)
* **Client Packager:** JSZip (In-memory zero-dependency ZIP archive generator)
* **State & Persistence:** LocalStorage & SessionStorage state sync
