# 🤝 Contributing to Project Graveyard

Thank you for contributing to **Project Graveyard: Conservatory Protocol**!

---

## 🌿 Engineering Workflow

1. **Branching Convention:**
   * `feat/feature-name` for new user-facing functionality.
   * `fix/bug-description` for defect resolutions.
   * `docs/documentation-update` for markdown specifications.

2. **Commit Standards:**
   We follow the [Conventional Commits](https://www.conventionalcommits.org/) specification:
   * `feat:` new feature
   * `fix:` bug fix
   * `style:` UI, theme, or animation adjustment
   * `docs:` documentation additions
   * `refactor:` code restructuring without behavior change

3. **Code Quality:**
   Ensure `npm run build` passes with zero TypeScript warnings before opening a Pull Request.
