# 🧭 The Revival Compass Methodology

> How Project Graveyard evaluates whether an abandoned codebase deserves resurrection.

---

## 🧮 Multi-Vector Viability Scoring (0–100)

The algorithm evaluates specimens across four fundamental vectors:

1. **Architecture Freshness (30%):** Evaluates dependency health, framework deprecation, and security posture.
2. **Functional Completion Ratio (25%):** Measures what percentage of core user journeys were implemented before stoppage.
3. **Salvageable Decoupling (25%):** Analyzes whether modules (Auth, Schema, UI Tokens) can be cleanly extracted.
4. **Market & Domain Opportunity (20%):** Evaluates problem-space relevance and competitive saturation.

---

## 🏁 The 120-Minute Focus Sprint

Once a specimen is designated a **Prime Candidate**, the system generates a prioritized 2-hour sprint roadmap:
* **Minutes 00–30:** Dependency pruning & secret scrubbing.
* **Minutes 30–75:** Core feature resurrection & test passes.
* **Minutes 75–105:** Clean UI polish & production build.
* **Minutes 105–120:** Live deployment & DNS configuration.
