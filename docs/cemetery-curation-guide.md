# Project Graveyard: Cemetery Curation & Specimen Vaulting Protocols (v1.0)

## 1. Purpose & Guiding Ethos
The cemetery is not an unorganized digital landfill; it is a meticulously curated conservatory herbarium. The curator’s duty is to honor the human dedication, late-night sprint sessions, and architectural ambitions embedded in dormant code repositories.

---

## 2. The 4 Stages of Curation

1. **Intake & Git Archaeology**:
   - Parse initial commit history, author distribution, and branch morphology.
   - Detect primary programming language, package managers (`pnpm`, `npm`, `yarn`, `cargo`), and runtime framework.

2. **Forensic Autopsy**:
   - Determine the root cause of demise via the 6 Forensic Archetypes.
   - Extract the developer’s last unfinished note from git commit messages or abandoned TODO tags.

3. **Salvage Harvesting**:
   - Identify modular units with zero relative imports outside their boundary.
   - Strip API keys, auth credentials, and staging database secrets using `codeSanitizer`.
   - Calculate lines of code and generate 1-click ESM export bundles.

4. **Revival Radar Calibration**:
   - Compute the normalized Revival Viability Score (0 - 100).
   - Generate the 120-minute revival sprint blueprint for future maintainers.

---

## 3. Preservation Ethics
- **Preserve Git Commit Authors**: Original authors must be prominently displayed on specimen archival plates.
- **Dignified Epitaph**: Every specimen must conclude with a poetic, respectful epitaph reflecting its conceptual dream.
